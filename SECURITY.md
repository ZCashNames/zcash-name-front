# Security

## Reporting a problem

Please report security problems privately to **info@zcashnames.co** rather than in a public issue.
Include what you found and how to reproduce it.

## What this repository covers

The website and web app of ZCash Name Service at https://zcashnames.co. The registrar and the indexer
are separate services with their own code.

## Checking the site yourself

https://zcashnames.co/security.html explains:

- what stays in your browser and every request the app makes, with what it sends and why;
- how to compare the live site with a release tag (`tools/verify.py`);
- how to run your own copy (`tools/serve.py`).
